# Contributing

Use English and synthetic data for every contribution. Never submit customer
logs, credentials, tokens, production identifiers, or private incident details.

Rules must be deterministic, reviewable, narrowly scoped, and accompanied by
positive and negative fixtures. Changes must pass pytest with the coverage gate,
Ruff checks, formatting, and both known-cause smoke tests. Document changes to
the evidence schema, redaction, finding contract, or model boundary.
