# Security Policy

Report vulnerabilities through GitHub Private Vulnerability Reporting when
available. Never include real evidence, credentials, tokens, customer names,
hostnames, or unredacted logs in a public issue.

Evidence files are untrusted input. Use an isolated environment for unknown
bundles, retain default redaction, inspect output before sharing, and apply
organization retention controls. Redaction is best-effort and is not a DLP
guarantee.

Remote model use sends redacted evidence outside the machine. Use only approved
endpoints and secret-management practices. No command performs remediation.
